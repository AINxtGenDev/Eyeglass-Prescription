# Readability pass for phone and desktop (dev-1.5)

1. Heading scale: h1 24 px (phone) to 32 px (desktop), h2 22 px, h3 18 px → verify: computed sizes in Chrome DevTools at 412 px and 1440 px.
2. Explanatory text and messages 14 px → 16 px; 14 px stays for labels, captions inside cards and the footer → verify: computed sizes.
3. Running text at most about 75 characters per line on desktop → verify: characters per line measured in Chrome DevTools at 1440 px.
4. Colours: keep the palette → verify: axe WCAG 2.2 AA (`e2e/a11y.spec.js`).
5. Gate: lint, unit tests, build, `a11y`, `layout`, `rx`, `smoke`, `results`, `view` specs.
