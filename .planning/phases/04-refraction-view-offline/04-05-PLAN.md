## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| main thread → warp worker (postMessage) | Structured-clone data crosses a thread boundary; the handler must not trust it |
| worker reply → drawn picture | A stale or mismatched reply would draw another input's picture |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-18 | Tampering (input validation) | createWarpHandler | mitigate | Per-item validation of surfaces, frame, eye, layout and tier; never throws; error reply for malformed messages |
| T-04-19 | Tampering (stale picture) | warp-client | mitigate | Generation + id filter, isWarpCurrent, cancel() on leaving Durchblick |
| T-04-20 | Denial of service (UI freeze) | warp job | mitigate | Dedicated worker off the main thread; watchdog with sync fallback one item per macrotask; numbers path untouched (engine worker separate) |
