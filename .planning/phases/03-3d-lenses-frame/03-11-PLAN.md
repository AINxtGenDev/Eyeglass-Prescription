    - layoutLabels(items, bounds): items = [{ id, priority (0 = callout, 1 = eye, 2 = iso), order, anchor: { x, y }, size: { w, h }, offset: { dx, dy } }], bounds = { w, h }. It returns a Map id → { x, y } for the visible labels only
    - a label's box is anchor + offset, clamped inside [0, w − size.w] × [0, h − size.h] (no overflow)
    - an iso label overlapping a callout is dropped; an eye label overlapping a callout is dropped; an iso label overlapping an eye label is dropped
    - two callouts that overlap: both are kept (callouts are never dropped; the table holds every number), and the later one in `order` is shifted down by its height + 4 px once
    - labels with a non-finite anchor (behind the camera after projection) are dropped
    - deterministic: the same input gives the same output
  </behavior>
