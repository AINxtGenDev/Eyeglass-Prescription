Slice 10: the expert reads the thickness numbers directly on the lens at nasal, temporal, superior, inferior and the centre, plus the iso-line values. The labels follow the view while the user turns it and never overlap. This completes VIZ-05.

    - layoutLabels(items, bounds): items = [{ id, priority (0 = callout, 1 = eye, 2 = iso), order, anchor: { x, y }, size: { w, h }, offset: { dx, dy } }], bounds = { w, h }. It returns `{ placed: Map id → { x, y } (visible labels only), calloutsFit: boolean }`
    - a callout tries the candidate boxes outward (anchor + offset), below, above, left, right (8 px gap) in that order and takes the first that lies fully inside [0, w] × [0, h] and overlaps no already placed callout; callouts are placed in `order`
    - if any callout has no candidate left → calloutsFit false and NO callout is in `placed` (all-or-nothing, MAJOR 4); eye and iso labels are then placed against an empty callout set
    - six 50×28 callouts around a 226×165 lens anchor set in a 288×216 stage (the example heat-eye framing at 320 px) → calloutsFit true, no overlap; the same six around a 73×53 lens (the old both-rims framing) → calloutsFit false
    - an iso label overlapping a callout is dropped; an eye label overlapping a callout is dropped; an iso label overlapping an eye label is dropped; eye and iso labels are clamped inside the bounds (no overflow)
    - labels with a non-finite anchor (behind the camera after projection) are dropped; a callout with a non-finite anchor makes calloutsFit false
    - deterministic: the same input gives the same output; no two returned boxes overlap (property test with fast-check, ≥ 200 random layouts)
  </behavior>
