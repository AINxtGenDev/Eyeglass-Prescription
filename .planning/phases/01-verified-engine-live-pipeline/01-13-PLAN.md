<interfaces>
From src/engine/metrics.js:
- `computeMetrics({ surfaces, outline, density, eye })` loops over the outline once. Inline it tracks iMax/iMin (thickness extremes, ties to the larger y) and iN/iT/iS/iI:
  - nasal = max of nasalSign(eye)·x; temporal = min of it;
  - superior = max y; inferior = min y.
  - These use strict comparisons, so the first index wins on ties.
- It returns `etMax/etMin = { value, index, location, x, y }`, `etAt = { nasal, temporal, superior, inferior }` (thickness values only, no indices), and `mbsMm = 2·maxRadiusFromOC + 2`.
- `maxRadiusFromOC(outline, oc)` returns the distance only. `thicknessAt(s, x, y) = s.ct − frontSagAt + backSagAt`.

From src/engine/design.js:
- `frontSagAt(s, x, y)` and `backSagAt(s, x, y)`: lens-local (boxing-centre) coordinates; both are sags along +z toward the eye, so a convex front and a concave back are both positive; NaN outside the domain.

From src/engine/evaluate.js:
- `intermediates = { n, D1, D1v, D2a, D2b, R1, Ra, Rb, rhoMax, vogelD1, vogelClampedD1, vogelMaxThickness, baseCurveRule, baseCurveSearch, bindingConstraint, iterations }`.
- `allFinite(intermediates)` guards against NaN (null is allowed).
- `m = MATERIALS[spec.materialId]`.

From src/engine/materials.js: each row has `ve` (νe, used with ne) and `vd`: cr39 56, trivex 45, pc 29, idx160 40, idx167 32, idx174 32, each with a cited source.

From src/ui/main.js:
- `renderMaterialLine(eye, materialId)` → `t('result.materialLine', { eye, label, density })`; the de-AT text is '{eye}: {label}, Dichte {density}'.
- `baseCurveText(m, im)`: `vogel = fmtDiopter(im.vogelClampedD1)`, then `basecurve.vogelRef` / `vogelRefThicker` / `vogelRefImpossible` with {vogel} (and {thickness}).

From src/state/parse.js:

- `parseAxis` fails with `PARSE_NOT_A_NUMBER` when `^\d{1,3}$` does not match after stripping `x|×|@` and `°`, and with `PARSE_AXIS_OUT_OF_RANGE` above 180.
- `parse.test.js` currently expects '45,5' → PARSE_NOT_A_NUMBER; that changes here.
