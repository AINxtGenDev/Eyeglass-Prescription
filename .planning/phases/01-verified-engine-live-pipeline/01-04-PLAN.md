## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions marketplace → runner | third-party action code runs with the workflow token |
| workflow token → repository / Pages | write scopes could publish or modify content |
| engine source → engine purity | a contributor (or agent) could import DOM/Three into the trust core |
