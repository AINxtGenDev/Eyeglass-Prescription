<interfaces>
From src/ui/main.js after 01-13:
- `update()`:
  - reads all fields;
  - computes `evaluatePair(currentSpecs)` when both eyes are ready, otherwise `evaluateLens(spec(eye))` per ready eye;
  - renders both eyes;
  - ends with `setText('timing-input', t('tech.inputRender', { ms }))`, where `ms` covers only update().
- `measure(specs)` runs 50 × evaluatePair → { median, p95 }.
- `runBench()` uses `currentSpecs ?? −2,00 fallback` for #timing and `WORST_CASE_BENCH_SPECS` for #timing-worst. `currentSpecs` exists only for runBench.
- `init()` wires the listeners:
  - 'input' → update on rx-*-sph/cyl/axis/pd and frame-a/b/dbl;
  - 'change' → update on #material and #frame-shape (the shape listener prefills A/B/DBL first);
  - 'toggle' on #tech → runBench; 'click' on #timing-rerun → runBench.
- `specFor(eye, rx, monoPD, materialId, frame, fittingHeight)` builds a LensSpec.
- `fmtForm(f)` gives "Sph / Zyl × Achse".
- `renderDiagnostics(eye, diagnostics)` always calls `box.replaceChildren(...items)` on #diag-od / #diag-os (role="status").
- `renderEmpty` also calls `replaceChildren()`.

From src/engine/frame/outline.js:
- `frameOutline(shape, A, B, eye, n)` caches OD outlines in a FIFO `CACHE` (size 16), keyed `${shape}|${A}|${B}|${n}`.
- OS mirrors the cached OD, so one A/B change gives one miss per pair.

From test/bench/recompute.test.js: `bench(pair)` does 10 warm-up runs and then 50 timed evaluatePair runs; it prints the medians and asserts ok, rule 'thinnest' and evaluations ≤ 40 per eye.

From src/i18n/de-AT.js: 'tech.timing' and 'tech.timingWorst' (the latter values spelled out in text, updated in 01-12), 'tech.inputRender': 'Letzte Eingabe bis Anzeige: {ms}', 'tech.rerun'.
