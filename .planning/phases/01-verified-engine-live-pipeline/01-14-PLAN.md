- **Playwright CDP session.** Playwright 1.65 types (node_modules/playwright-core/types/types.d.ts) declare `browserContext.newCDPSession(page: Page|Frame): Promise<CDPSession>` with the note "CDP sessions are only supported on Chromium-based browsers". `cdpSession.send(method, params)` is documented at https://playwright.dev/docs/api/class-cdpsession.
- **4× multiplier.** Lighthouse: "By default, Lighthouse uses a constant 4x CPU multiplier which moves a typical run in the high-end desktop bracket somewhere into the mid-tier mobile bracket". Source: https://github.com/GoogleChrome/lighthouse/blob/main/docs/throttling.md
