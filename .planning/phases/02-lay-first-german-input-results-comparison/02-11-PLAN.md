Derivation for lens-critic (RESEARCH Open Q2 / A1, re-derived here, standard conic algebra):
the conic sag z with vertex radius R = 1/c and conic constant k satisfies r² = 2Rz − (1 + k)z² (square the rationalised form z(1 + √(1 − (1 + k)c²r²)) = c r² and simplify). The executor proves it in sag.test.js: sphereSag(c, r², k) satisfies r² − 2z/c + (1 + k)z² = 0 to 1e-9 relative for random c, r, k. Jalie US4289387 writes y² = 2000(n′ − n)x/F₀ − p·x², i.e. 2R = 2000(n′−n)/F₀ and p = 1 + k. Jalie's p from 0 to −4 is therefore k from −1 to −5 → default k = −1 (mildest cited end), UI range −5,0…−1,0 (only the cited range, lens-critic MINOR-2; k = 0, the sphere, is the 'sphärisch' radio, and −1 < k < 0 is not offered because no source covers it). The patent applies the hyperboloidal surface to the front for plus (positive) lenses only and to the back for minus lenses (verified 2026-11-07 on patents.google.com/patent/US4289387A: 'for positive powered lenses with an anterior surface of a hyperboloidal form', 'for minus powered lenses, with a posterior surface of a hyperboloidal form'); the model applies k to the front for any Rx as a generic surface, and the asphere note says it mainly changes plus lenses. Write both facts in the citation comment.
