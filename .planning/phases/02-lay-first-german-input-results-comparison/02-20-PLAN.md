- **MJ-1 (MAJOR):** the deferred compare start must be scheduled AFTER the input frame's end stamp. `runFrame` (src/ui/timing.js:164-176) calls `update(inputTs)` and only then queues the measuring setTimeout that stamps `timings.inputFrame`/`reaction`; posting from inside `update()` would run first and be counted inside the input frame.
