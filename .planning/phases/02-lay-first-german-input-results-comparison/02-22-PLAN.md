<objective>
Close the measurement part of lens-critic M4. 02-20 showed by trace that 10–16 ms of every measured 4× input frame is a Playwright DevTools-session task (blink.mojom.DevToolsSession, 'Receive mojo message') that runs after the frame is painted and before the timer that records the frame end. A real phone does not run it. App work in those frames was at most 9,7–11,8 ms. The user chose to fix the measurement (2026-11-07). This plan makes the harness quiet during a measured frame, proves by trace that only harness work was removed, and re-measures.

Not in scope: any app code change, and loosening the 16,7 ms rule.
</objective>
