Derivation for lens-critic (RESEARCH Open Q2 / A1, re-derived here, standard conic algebra):
the conic sag z with vertex radius R = 1/c and conic constant k satisfies r² = 2Rz − (1 + k)z² (square the rationalised form z(1 + √(1 − (1 + k)c²r²)) = c r² and simplify). The executor proves it in sag.test.js: sphereSag(c, r², k) satisfies r² − 2z/c + (1 + k)z² = 0 to 1e-9 relative for random c, r, k. Jalie US4289387 writes y² = 2000(n′ − n)x/F₀ − p·x², i.e. 2R = 2000(n′−n)/F₀ and p = 1 + k. Jalie's p from 0 to −4 is therefore k from −1 to −5 → default k = −1 (mildest cited end), UI range −5,0…0,0 (k = 0 sphere included as the boundary).
Rim depth: no citable default → RIM_DEPTH_DEFAULT_MM = 3.0 [ASSUMED, RESEARCH A2], shown as "angenommener Wert".
